## 📖 О проекте

**TimeSheet Manager** — это корпоративный инструмент для ведения табеля учёта рабочего времени, разработанный специально для нужд моего отдела.  

Система позволяет:
- Фиксировать отработанные часы (**день** и **ночь**)
- Привязывать смены к конкретному **объекту (площадке)**
- Автоматически **рассчитывать зарплату** по заданным ставкам
- Хранить все данные в **Google Sheets** — доступно с любого устройства

Проект создан **полностью с использованием искусственного интеллекта** (включая генерацию кода, архитектуру и документацию) как эксперимент по ускорению внутренней разработки.

---

## ✨ Основные возможности

| Функция | Описание |
|---------|----------|
| 🕒 **Дневные / ночные часы** | Раздельный учёт с возможностью разных ставок оплаты |
| 🏢 **Привязка к объекту** | Каждая запись содержит метку объекта (адрес, номер площадки) |
| 💰 **Автоматический расчёт ЗП** | Итоговая сумма за период с учётом всех коэффициентов |
| ☁️ **Облачное хранение** | Данные синхронизируются с Google Sheets |
| 👥 **Удобный интерфейс** | Простой ввод данных без лишних шагов |
| 📈 **Сводка по сотрудникам** | Суммарные показатели за период |
